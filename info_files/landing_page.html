Core Algorithmic Foundations

Algorithms & Their Agent Use Cases

Every mathematical heuristic, vector optimization, and verification algorithm powering the multi-agent architecture.

Stage 4 — Analyzing

Maximal Marginal Relevance Diversity Algorithm

Computes vector similarity metrics between search sub-questions and candidate text blocks while penalizing cross-source duplication. Ensures synthesized evidence contains maximum factual novelty with zero redundant paragraphs.

Stage 3 & 4 — Search & Rank

Domain Tier Authority & Lexical Scoring

Multiplies term frequencies by domain authority coefficients (.edu, .gov, peer-reviewed journals vs vendor blogs) to filter promotional content and rank top 1% empirical sources.

Stage 6 — Auditing

Dynamic Knowledge Gap Detection & Recourse

Uses LLM-based zero-shot coverage grading to classify responses as COMPLETE, PARTIAL, or MISSING. For gaps, algorithmically formulates new search queries and triggers recursive loops.

Stage 2 — Recall

768-Dimensional Cosine Vector Memory Recall

Converts operational lessons into 768-d nomic embeddings and executes Supabase RPC cosine similarity queries to inject past research failure modes directly into planning prompts.

Stage 8 — Reporting

Programmatic Anti-Hallucination QA Rule-Pass

Runs multi-pattern regex verification across report drafts to cross-check all numerical metrics, dates, and percentages against raw scraped web text, flagging unbacked statistics.

Stage 9 — Scoring

LLM-as-Judge 5D Quality Telemetry

Evaluates outputs across 5 quantitative dimensions — Relevance, Depth, Novelty, Coherence, Citation Accuracy — recording execution telemetry and saving operational lessons for future runs.
